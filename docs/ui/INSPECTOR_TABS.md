# 🔍 Специализированные вкладки инспектора деталей (Tabs 1-7)

В нижней левой панели **NullCA Cockpit** располагается глубокий протокольный инспектор с 7 тематическими вкладками. Переключение осуществляется клавишами `[1]` — `[7]` или кликом мыши по заголовку вкладки.

---

### [1] Info & Headers
Базовая вкладка, адаптирующаяся под обнаруженный протокол перехваченного пакета:
- **HTTP/1.1 и HTTP/2**:
  - Полный список декодированных заголовков (псевдо-заголовки `:method`, `:path`, `:status`, `:scheme` для HTTP/2).
  - Красивый бейдж статуса ответа (`200 OK`, `404 Not Found`, `500 Internal Error`).
  - Форматированное тело сообщения (текст или JSON).
- **Базы данных (PostgreSQL / MySQL)**:
  - Выделенный текст SQL-запроса с форматированием команд `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `FROM`, `WHERE`.
- **Redis (RESP)**:
  - Выделенная красным цветом команда (`SET`, `GET`, `HGETALL`, `AUTH`, `EVAL`) и нумерованный список переданных аргументов.
- **SMTP**:
  - Разобранные почтовые команды (`EHLO`, `MAIL FROM`, `RCPT TO`, `DATA`).

---

### [2] Protobuf Tree
Автоматический разбор неструктурированных бинарных Protocol Buffers полезных нагрузок без необходимости наличия исходных `.proto` файлов:
- Отображает схему в виде читаемого JSON-дерева с номерами полей (field tags) и типами wire format:
  - `Varint` (целые числа, boolean, enums).
  - `Fixed64` / `Fixed32` (числа с плавающей точкой, таймстемпы).
  - `LengthDelimited` (строки, байтовые массивы, вложенные сообщения).
- Автоматически снимает 5-байтовый gRPC заголовок кадрирования (`compressed flag` + `length`).

---

### [3] Secrets & CTF Flags
Вкладка автоматического анализа безопасности и харвестинга секретов:
- **JWT (JSON Web Tokens)**:
  - Моментально обнаруживает сигнатуры `eyJ...`.
  - Автоматически декодирует Base64URL-блоки заголовка и полезной нагрузки (Claims).
  - Показывает поля `sub`, `iss`, `exp`, `roles`, `permissions` в виде отформатированного JSON.
- **CTF Flags**:
  - Распознает флаги по регулярным выражениям: `flag{...}`, `CTF{...}`, `FLAG{...}` и hex/base64 хэши.
  - Подсвечивает местонахождение флага в потоке.
- **Учётные данные**:
  - Детектирует AWS Access Keys (`AKIA...`), токены GitHub (`ghp_...`), Bearer-токены и Basic Authentication с автоматической расшифровкой `username:password`.

---

### [4] cURL Command
Генерирует полностью готовую команду cURL для терминала:
- Учитывает метод, путь, все перехваченные заголовки (включая Cookie и Auth) и тело запроса.
- Пример:
  ```bash
  curl -X POST "https://api.internal:8443/auth/token" \
    -H "Host: api.internal:8443" \
    -H "Authorization: Bearer eyJhbGciOi..." \
    -H "Content-Type: application/json" \
    --data '{"grant_type":"client_credentials"}'
  ```

---

### [5] WebSocket Stream Inspector
Специализированный диссектор фреймов протокола RFC 6455:
- **Unmasking**: автоматическое снятие 4-байтовой маски полезной нагрузки фреймов клиента без ручных XOR-операций.
- **Frame Headers**: отображение параметров `Opcode` (Text, Binary, Ping, Pong, Close), `FIN`-флага и размера фрейма.
- **Reassembly**: сборка фрагментированных текстовых сообщений из нескольких последовательных фреймов в единое целое.
- **JSON Formatting**: автоматическое форматирование JSON-полезных нагрузок внутри вебсокетов.

---

### [6] X.509 PKI & Certificate Inspector
Глубокий ASN.1 инспектор инфраструктуры открытых ключей и сертификатов:
- **Субъект и Эмитент**: Common Name (CN), Organization (O), Organizational Unit (OU), Country (C).
- **Криптография**:
  - Алгоритм открытого ключа (RSA 2048/4096, ECDSA P-256/P-384/P-521, Ed25519, Ed448).
  - Постквантовые алгоритмы: ML-DSA (Dilithium-2/3/5), ML-KEM (Kyber).
  - Национальные шифры: ГОСТ Р 34.10-2012 / 34.11-2012, китайские SM2 / SM3.
- **Срок действия**: точные даты NotBefore и NotAfter с индикатором истечения и обратным отсчетом в днях.
- **SANs**: полный список альтернативных доменных имен Subject Alternative Names.
- **Списки отзыва (CRL)** и запросы на подпись сертификатов (CSR).
- **Хэш-отпечатки**: криптографические фингерпринты SHA-256 и SHA-1.

---

### [7] Diff Inspector (Myers / LCS Engine)
Встроенный механизм визуального сравнения двух пакетов:
- Нажатие `[d]` на одном пакете фиксирует его как базовый (отмечается иконкой 📌).
- При переходе на любой другой пакет вкладка `[7]` моментально отображает различия:
  - Добавленные строки заголовков и параметров (зелёная подсветка `+`).
  - Удалённые или изменённые поля (красная подсветка `-`).
  - Изменения значений заголовков: `Header: old_value -> new_value`.
  - Построчный дифф форматированного тела ответа или запроса.
