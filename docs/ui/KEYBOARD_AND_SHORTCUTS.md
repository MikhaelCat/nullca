# ⌨️ Справочник горячих клавиш и управления (Cockpit Shortcuts)

Терминальный интерфейс **NullCA Cockpit** полностью оптимизирован для быстрого управления без мыши, но также поддерживает работу мышью и тачпадом.

---

## 🎯 Навигация и перемещение фокуса

| Клавиша | Действие |
| :--- | :--- |
| `[Tab]` | Переключение активного фокуса между панелями: `PacketTable` ⇄ `DecodedDetails` ⇄ `Hexdump` |
| `[Shift + Tab]` | Переключение фокуса в обратном порядке |
| `[j]` / `[Down]` | Следующий пакет в таблице / прокрутка вниз в окне деталей или хекса |
| `[k]` / `[Up]` | Предыдущий пакет в таблице / прокрутка вверх в окне деталей или хекса |
| `[PageDown]` | Быстрая прокрутка на 10 элементов/строк вниз |
| `[PageUp]` | Быстрая прокрутка на 10 элементов/строк вверх |
| `[g]` / `[Home]` | Перейти к первому пакету / в начало буфера деталей |
| `[G]` / `[End]` | Перейти к последнему пакету / в конец буфера деталей |
| `[f]` / `[m]` | **Toggle Fullscreen**: максимизировать активную панель на весь экран / вернуть 3-панельный вид |
| `[Esc]` | Выход из полноэкранного режима, очистка Diff baseline или закрытие активного модального окна |

---

## 🗂️ Вкладки инспектора деталей (`[1 - 7]`)

При фокусе на окне деталей или в глобальном режиме цифровые клавиши мгновенно переключают активную вкладку:

| Клавиша | Вкладка | Описание |
| :---: | :--- | :--- |
| `[1]` | **Headers & Info** | Декодированные заголовки HTTP/1.1 и HTTP/2, SQL-запросы, команды Redis RESP, SMTP |
| `[2]` | **Protobuf Tree** | Иерархическое дерево декодированных бинарных Protobuf / gRPC структур |
| `[3]` | **Secrets & Flags** | Сводка обнаруженных JWT-токенов, AWS-ключей и CTF-флагов |
| `[4]` | **cURL** | Готовая к исполнению команда cURL со всеми заголовками и телом |
| `[5]` | **WebSocket** | Разобранные фреймы RFC 6455 (Opcode, FIN, Mask, unmasked payload, JSON) |
| `[6]` | **X.509 PKI** | Разбор сертификатов X.509, SANs, срока действия, списков отзыва CRL и запросов CSR |
| `[7]` | **Diff Inspector** | Построчное сравнение Myers/LCS с базовым пакетом |

## ⚡ Атакующие инструменты, Replay и экспорт

| Клавиша | Действие | Описание |
| :---: | :--- | :--- |
| `[R]` / `[t]` | **Request Repeater & Tamper** | Открыть интерактивное модальное окно редактирования и повторной отправки HTTP-запроса |
| `[r]` | **Fast Replay** | Немедленная повторная отправка выделенного запроса на целевой сервер с замером TTFB и латентности |
| `[d]` | **Diff Baseline** | Пометить выделенный пакет как базовый (📌). Повторное нажатие на другом пакете открывает окно сравнения |
| `[c]` | **Copy cURL** | Сгенерировать команду `curl` для выделенного запроса и вывести в статус-бар |
| `[s]` | **Save & Export Menu** | Открыть модальное меню сохранения сырого тела, cURL-скрипта, PCAP-NG, HAR 1.2 или OpenAPI 3.0 |
| `[x]` | **Clear Buffer** | Очистить накопленный буфер пакетов в оперативной памяти |
| `[Space]` / `[p]` | **Pause / Resume** | Приостановить или возобновить прием пакетов из BPF-кольцевого буфера |
| `[/]` | **Filter DSL** | Активировать строку ввода Filter DSL для мгновенной фильтрации пакетов |
| `[?]` / `[h]` | **Help Modal** | Открыть всплывающее окно справки по всем горячим клавишам |
| `[q]` | **Quit** | Корректно завершить работу Cockpit и восстановить терминал |

## 🖱️ Поддержка мыши (Mouse Gestures)

- **Колесо мыши вверх / вниз**:
  - В таблице пакетов: перемещает курсор выбора пакета.
  - В окне деталей: плавно прокручивает разобранные заголовки, деревья Protobuf или текст.
  - В окне Hexdump: прокручивает байтовый дамп пакета.
- **Левый клик мыши**:
  - Клик по строке в таблице: немедленно выбирает соответствующий пакет.
  - Клик в область строки фильтра: активирует режим редактирования DSL.
  - Клик в левую или правую нижнюю панель: переключает фокус ввода между деталями и хекс-дампом.
